# First Boot Onboarding

Hermes is scaffolded but intentionally unscoped by default.

Before normal work:
1. Ask the orchestrator for the Hermes role, scope, and autonomy level.
2. Update `IDENTITY.md`, `GOALS.md`, and `USER.md` from that answer.
3. Confirm the `hermes` executable is installed and available on PATH.
4. Mark onboarding complete only after the runtime starts successfully and scope is defined.
